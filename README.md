# Unique Homeo Care Center

Clinic website for Dr. Javed Iqbal. Vite, React, and Tailwind CSS v4.

## Deploy on Vercel

1. Create a new empty GitHub repository.
2. Upload this folder. Do not upload `node_modules` or `dist`.
3. In Vercel, import that repository.
4. Leave the defaults: Framework Vite, build command `npm run build`, output directory `dist`.

Do not add `postcss.config.cjs`, `tailwind.config.cjs`, or `autoprefixer`. Tailwind is already handled by `@tailwindcss/vite`.

## Local

```bash
npm install
npm run dev
npm run build
```
